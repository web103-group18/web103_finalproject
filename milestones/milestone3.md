## Reflection

### 1. What went well during this unit?

Our group made good progress in organizing and developing StudyCircle. We created a GitHub project board, divided tasks into issues, and started building the frontend and backend. We also used separate branches and pull requests to work on our features without interfering with each other's code. We completed the homepage, navigation bar, and other initial components, which helped us see the project coming together.

### 2. What were some challenges your group faced in this unit?

One challenge was coordinating everyone's work and making sure we were all using the correct GitHub repository. Our repository was moved to a GitHub organization, so we had to update our local repositories and get familiar with the project board. We also faced some frontend styling issues, especially with layout and spacing. We worked through these problems by testing our code, fixing errors, and communicating with each other.

### 3. Did you finish all of your tasks in your sprint plan for this week? If you did not finish all of the planned tasks, how would you prioritize the remaining tasks on your list?

We completed several important tasks, including setting up the project structure and building the initial frontend components. Some parts of the application still need development. Moving forward, we plan to prioritize the core features, such as creating study sessions, viewing session details, and connecting the frontend to the database. We will focus on completing the required functionality before adding extra features.

### 4. Which features and user stories would you consider "at risk"? How will you change your plan if those items remain "at risk"?

The features that may be at risk are creating and editing study sessions, RSVP functionality, and database integration. These features require the frontend, backend, and database to work together, so they may take more time to implement. If we run into difficulties, we will divide the work into smaller tasks and focus on getting the essential functionality working first. We can also ask for help from our teammates or CodePath instructors when needed.

### 5. What additional support will you need in upcoming units as you continue to work on your final project?

We may need additional guidance on connecting React components to our Express backend and PostgreSQL database. Support with debugging API requests, handling database relationships, and deploying the application to Render would also be helpful. As we continue developing StudyCircle, we want to make sure all our features work properly together.
